# دموی بخش اول: نمای تعاملی C4

`c4-explorer.html` نمای C4 دستیار پشتیبانی فروشگاه است و کاملاً بدون اینترنت کار می‌کند.

- از لانچر: `python run_all.py` و در صفحهٔ http://127.0.0.1:8080 کارت «بخش اول — معماری C4» → «باز کردن دمو» (نشانی: http://127.0.0.1:8080/part1/demo/c4-explorer.html).
- بدون لانچر: همین فایل را مستقیم در مرورگر باز کنید.
- `vendor/tailwindcss-play.js`: نسخهٔ محلی Tailwind CSS 3.4.17 (به جای cdn.tailwindcss.com).
- `vendor/fonts.css` و `vendor/fonts/`: فونت‌های Vazirmatn، JetBrains Mono و IBM Plex Mono (woff2، مجوز OFL) به جای Google Fonts. فونت‌های IBM Plex Mono و Vazirmatn را frontend بخش ۲ هم از طریق `launcher/next_font_mock.js` می‌خواند.
