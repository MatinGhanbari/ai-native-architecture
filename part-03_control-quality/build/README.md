# ساخت نسخهٔ ۲ اسلایدهای بخش ۳

`build_v2.py` نسخهٔ ۱ را از `slides/archive/part-03_v1.pptx` می‌خواند، شکل‌های `fig/` و تصویرهای `ui_shots/` را اضافه می‌کند و نتیجه را در `slides/part-03_v2.pptx` می‌نویسد.

از پوشهٔ `part-03_control-quality` یا با مسیر کامل فایل:

```bash
python build/build_v2.py
```

نیاز به `python-pptx` و فونت AradFDVF نصب‌شده روی سیستم دارد. این فونت تجاری است و در مخزن نیست.
