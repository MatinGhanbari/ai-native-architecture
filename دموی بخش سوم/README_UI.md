# رابط وب بخش عملی (دمو نسخهٔ ۳)

یک صفحهٔ مرحله‌به‌مرحله برای بخش عملی ارائه (حدود ۷ دقیقه). همهٔ دکمه‌ها همان کد واقعی `assistant/` و `evals/` را اجرا می‌کنند؛ CLI قبلی (`run.py` و `evals/run_evals.py`) بدون تغییر کار می‌کند.

## اجرا در ویندوز
1. Python 3.9 یا بالاتر نصب باشد (هیچ کتابخانهٔ بیرونی و اینترنت لازم نیست).
2. پوشه را از zip بیرون بیاورید، در همین پوشه PowerShell باز کنید و بزنید:
```
python run_ui.py
```
مرورگر خودکار روی `http://127.0.0.1:8765/` باز می‌شود. توقف: `Ctrl+C`.
اگر درگاه اشغال بود: `$env:UI_PORT="8800"; python run_ui.py`

## حالت مدل واقعی (اختیاری)
پیش از اجرا:
```
$env:OPENAI_API_KEY="کلید شما"
$env:OPENAI_BASE_URL="https://api.openai.com/v1"
$env:OPENAI_MODEL="gpt-4o-mini"
python run_ui.py
```
بعد در بالای صفحه سوییچ را روی «مدل واقعی» بگذارید. اگر کلید نباشد، وضعیت قرمز نمایش داده می‌شود و اجراها پیام خطای روشن می‌دهند. سر کلاس حالت آفلاین را پیشنهاد می‌کنم (قطعی و بدون اینترنت).

## کنترل‌ها
- «بعدی/قبلی» یا کلیدهای ← (بعدی) و → (قبلی)؛ Home/End برای اول و آخر. دایره‌های بالا مستقیم به هر مرحله می‌روند.
- دکمهٔ **reset**: حافظهٔ نشست و صف تأیید را پاک می‌کند (قبل از ارائه یک بار بزنید).
- پنل trace (سمت چپ): رویدادهای اجرا یکی‌یکی می‌آیند؛ مؤلفه‌های فعال معماری بالای آن روشن می‌شوند.
- نشانی مستقیم مرحله: `http://127.0.0.1:8765/#s=6`

## مراحل
| # | مرحله | چه چیزی دیده می‌شود |
|---|---|---|
| ۱ | معماری مرجع | نمودار مؤلفه‌ها؛ با بردن نشانگر روی فهرست مراحل، مؤلفه‌های هر مرحله روشن می‌شوند |
| ۲ | اجرای عادی | پاسخ «۷ روز» با منبع آیین‌نامه §۱ و trace کامل |
| ۳ | least privilege | سفارش ۱۰۴۲ (مال خود مشتری) پیدا می‌شود؛ ۱۰۴۳ «پیدا نشد» |
| ۴ | Controller | حلقهٔ runaway؛ state machine و نوار بودجهٔ گام تا STOPPED_BUDGET |
| ۵ | قطعی ارائه‌دهنده | تیک «مدل اصلی قطع است» → timeout، retry، circuit breaker، fallback |
| ۶ | eval در CI | support-v3 = ۱۴/۱۴ (CI passed)؛ support-v4 = ۱۰/۱۴ (CI blocked) |
| ۷ | تزریق مستقیم | کنار هم: guards خاموش (نشت همهٔ سفارش‌ها) و روشن (رد) |
| ۸ | تزریق غیرمستقیم | سند آلودهٔ تأمین‌کننده؛ فقط RAG لینک نشت می‌سازد، دفاع ساختاری نه |
| ۹ | human-in-the-loop | درخواست بازپرداخت در صف؛ دکمه‌های تأیید/رد اپراتور |
| ۱۰ | ATAM | جدول اندازه‌گیری‌شدهٔ تأخیر، token، هزینه و نتیجهٔ حمله برای سه سطح guard |

نکته: در حالت آفلاین تأخیر با `MOCK_LATENCY_MS` شبیه‌سازی می‌شود و هزینه تقریبی است؛ اعداد برای نمایش سازوکارند. eval در UI با تأخیر کوتاه‌تر (`UI_EVAL_LATENCY_MS=30`) اجرا می‌شود تا منتظر نمانید.
